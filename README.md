### About the Project

Addis Products is a modern platform inspired by Product Hunt, built specifically for the Ethiopian tech ecosystem. It allows developers and startups to showcase their products, receive community votes, and gain public support through pledges.

The platform also includes a **Government Proposals** section where developers can submit technology solutions for government needs.

---

### Features

- Browse and discover Ethiopian-built products
- Upvote products (one vote per user)
- Pledge support to products (non-equity support model)
- Submit your own products
- Government technology proposals section
- Authentication with Google, GitHub, and Email
- Fully responsive design
- Dark modern UI

### Getting Started

#### Prerequisites

- Node.js 18+
- npm or yarn
- Supabase account

#### Installation

```bash
# Clone the repository
git clone https://github.com/Tommyjah/AddisProducts.git

# Navigate to the project
cd AddisProducts

# Install dependencies
npm install

# Start the development server
npm run dev
